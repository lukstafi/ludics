# Add _build_review* to worktree git exclude entries

## Goal

Prevent `_build_review*` directories (e.g., `_build_review/`, `_build_review_round3/`) from being accidentally committed during orchestrated review sessions. These are temporary build artifacts created by reviewer agents using alternative build directories, and were observed leaking into commits during task-676f072f.

Related: follow-up from task-676f072f retrospective. The `ensureGitExcludes` infrastructure (introduced by task-9c479d00) already handles writing exclude patterns; this task adds the missing pattern.

## Acceptance Criteria

- `_build_review*` is present in the `GIT_EXCLUDE_ENTRIES` array in `src/orchestration/worktrees.ts`
- All worktrees created by `createWorktrees()` automatically exclude `_build_review*` artifacts via `.git/info/exclude`
- The `autoCommitWorktree` pathspec exclusions (derived from `GIT_EXCLUDE_ENTRIES`) also cover `_build_review*`

## Context

- **`src/orchestration/worktrees.ts` lines 25-32**: `GIT_EXCLUDE_ENTRIES` array is the single source of truth for patterns written to `.git/info/exclude`. Currently contains: `.peer-sync`, `.ludics-orchestration.json`, `.claude`, `.agents`, `.agent-sessions`, `node_modules`.
- **`src/orchestration/worktrees.ts` lines 42-63**: `ensureGitExcludes()` reads the existing exclude file and appends any missing entries from the array. Already idempotent.
- **`src/orchestration/worktrees.ts` line 250-251**: `ORCHESTRATION_EXCLUDES` is derived from `GIT_EXCLUDE_ENTRIES` via `.map()`, so adding to the array automatically updates the auto-commit pathspec exclusions too.
- No new call sites, functions, or tests are needed.

## Approach

*Suggested approach -- agents may deviate if they find a better path.*

Add `"_build_review*"` as a new entry in the `GIT_EXCLUDE_ENTRIES` array (after `"node_modules"`). This is a one-line change; the existing infrastructure handles everything else.

## Scope

**In scope:** Adding the `_build_review*` glob pattern to `GIT_EXCLUDE_ENTRIES`.

**Out of scope:** Adding `_build/` itself (projects manage that via their own `.gitignore`). No new tests required -- existing test coverage for `ensureGitExcludes` validates the mechanism; adding an array entry does not change behavior.
