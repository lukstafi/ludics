# Proposal: Refactor computeSlotLiveness to take slot context struct

**Task**: task-54b564a2
**Project**: ludics
**Date**: 2026-04-03

## Goal

Replace the positional primitive parameters of `computeSlotLiveness(slotNum, mode)` with a single `SlotLivenessContext` struct. This makes the function easier to extend when federation (task-6b3772fc) adds remote-slot fields, and improves call-site readability.

## Acceptance Criteria

- `computeSlotLiveness` accepts a single `SlotLivenessContext` struct parameter instead of `(slotNum: number, mode: string | null)`
- The `SlotLivenessContext` interface is exported from `src/dashboard.ts`
- The call site in the slot-parsing loop (~line 269) passes a struct literal
- All 7 existing tests in `src/dashboard.test.ts` pass with the new signature (updated `getLiveness` helper)
- Pure refactor: no behavior change

## Context

- **Function location**: `src/dashboard.ts` line 48
- **Single call site**: `src/dashboard.ts` line 269, inside the slot-parsing loop
- **Tests**: `src/dashboard.test.ts` lines 66-119, 7 test cases behind a `getLiveness(slot, mode)` helper
- **Parent task**: task-6b3772fc (federation remote slot state) will later extend the struct with fields like `machineName` and `harnessDir`
- **Related**: gh-ludics-121 (dashboard liveness)

## Approach

1. **Add interface** in `src/dashboard.ts` above the function:
   ```ts
   export interface SlotLivenessContext {
     slotNum: number;
     mode: string | null;
   }
   ```

2. **Change function signature** to destructure the struct:
   ```ts
   export function computeSlotLiveness(
     ctx: SlotLivenessContext,
   ): "alive" | "interrupted" | null {
     const { slotNum, mode } = ctx;
     // ... rest unchanged
   }
   ```

3. **Update call site** (line 269):
   ```ts
   liveness = computeSlotLiveness({ slotNum: num, mode: getMode(block).trim() || null });
   ```

4. **Update test helper** (line 68-71):
   ```ts
   async function getLiveness(slot: number, mode: string | null) {
     const { computeSlotLiveness } = await import("./dashboard.ts");
     return computeSlotLiveness({ slotNum: slot, mode });
   }
   ```

5. **Run tests**: `bun test src/dashboard.test.ts` to confirm no regressions.

Minimal struct (two fields only) keeps scope small. The federation parent task will widen it as needed.
