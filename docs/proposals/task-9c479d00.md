# Proposal: Add .git/info/exclude entries during worktree creation

**Task:** task-9c479d00 — Audit auto-commit and add local .gitignore to prevent committing workflow infrastructure

## Goal

Prevent agents from accidentally committing workflow infrastructure files (node_modules symlinks, .peer-sync, .ludics-orchestration.json, .claude, .agents) by writing `.git/info/exclude` entries during worktree creation. This complements the existing pathspec-based exclusions in `autoCommitWorktree`, which only protect ludics-initiated git commands but not agent-initiated ones.

## Acceptance Criteria

1. After `createWorktrees()` completes, each created worktree has `.git/info/exclude` entries for: `.peer-sync`, `.ludics-orchestration.json`, `.claude`, `.agents`, `.agent-sessions`, `node_modules`
2. The main project repo's `.git/info/exclude` also gets the same entries (defensive measure against agents running git commands in the wrong directory)
3. Exclude entry writing is idempotent — running `createWorktrees()` multiple times does not duplicate entries
4. Existing content in `info/exclude` files is preserved (append-only)
5. The `info/` directory is created if it does not exist (handles fresh repos)
6. The `ORCHESTRATION_EXCLUDES` pathspec list in `autoCommitWorktree` remains as a belt-and-suspenders defense
7. `node_modules` entry uses no trailing slash (to match symlinks, not just directories)

## Context

- **Root cause**: PR #110 committed a circular `node_modules` symlink and `.ludics-orchestration.json` because agents ran their own `git add`/`git commit` commands that bypassed ludics pathspec exclusions
- **Reference pattern**: agent-duo/agent-pair writes to `.git/info/exclude` using grep-based deduplication (lines 522-532 of `agent-pair`)
- **Key file**: `src/orchestration/worktrees.ts` — `createWorktrees()` function (line 75)
- **Callers**: `src/adapters/t3code.ts` (line 823), `src/adapters/tmux-adapter.ts` (line 416) — both go through `createWorktrees()`, so a single fix covers both adapters

## Approach

Add a helper function `ensureGitExcludes(dir: string, entries: string[])` to `worktrees.ts` that:
1. Resolves the git directory via `git rev-parse --git-dir` (works correctly for both regular repos and worktrees, returning e.g. `/path/to/main/.git/worktrees/<name>`)
2. Reads the existing `info/exclude` file content (if any)
3. Appends entries not already present (line-based deduplication)
4. Creates the `info/` directory if needed

Call this helper from `createWorktrees()`:
- Once for each unique worktree path (root + agent worktrees), after worktree creation
- Once for the main `projectDir` itself

The entries list:
```
.peer-sync
.ludics-orchestration.json
.claude
.agents
.agent-sessions
node_modules
```

Uses `readFileSync`/`writeFileSync`/`mkdirSync` from Node fs (already imported in the file) plus `runGit` for `git rev-parse --git-dir`. No new dependencies needed.
