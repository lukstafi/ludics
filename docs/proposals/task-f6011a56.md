# Consolidate proposal-read instruction into shared PROPOSAL_INSTRUCTION variable across templates

## Goal

Eliminate duplicated proposal-read conditional blocks across orchestration templates by computing a single `PROPOSAL_INSTRUCTION` variable in `buildSkillContext()`. Templates then insert `{{PROPOSAL_INSTRUCTION}}` directly instead of each carrying its own `{{#IF PROPOSAL_PATH}}...{{/IF}}` block with slightly inconsistent wording. This also fixes the reviewer-review template which currently renders an empty backtick pair when no proposal exists, and adds proposal awareness to reviewer planning templates that previously lacked it.
