# Extract clearDeferralFlags helper and move findSlotForTask to slots module

## Goal

Two focused refactors to improve module cohesion and reduce duplication:

1. Extract a `clearDeferralFlags(taskFile)` helper from the repeated `removeFrontmatterField(file, "deferred_launch"); removeFrontmatterField(file, "approved")` pattern across `mag.ts` and `dashboard-server.ts`.
2. Move `findSlotForTask` from `src/mag.ts` to `src/slots/index.ts`, where its dependencies already live.

## Acceptance Criteria

1. A `clearDeferralFlags(taskFile: string)` function is exported from `src/tasks/markdown.ts` (alongside `removeFrontmatterField`). It removes both `deferred_launch` and `approved` frontmatter fields.
2. All call sites that previously called `removeFrontmatterField(f, "deferred_launch"); removeFrontmatterField(f, "approved")` in sequence now call `clearDeferralFlags(f)` instead. Sites that clear only one field continue to use `removeFrontmatterField` directly.
3. `findSlotForTask` is exported from `src/slots/index.ts` (not from `src/mag.ts`). Its behavior is identical to the current implementation.
4. All callers of `findSlotForTask` — in `src/mag.ts` and `src/dashboard-server.ts` — import it from `src/slots/index.ts`.
5. No existing tests break. No functional behavior changes.

## Context

**Deferral flag clearing** (`src/mag.ts`):

The pattern `removeFrontmatterField(f, "deferred_launch"); removeFrontmatterField(f, "approved")` appears at the following sites in `src/mag.ts`:

| Approx. line | Function | Clears deferred_launch | Clears approved |
|---|---|---|---|
| 679–680 | `abandonTaskFromNotification` (unslotted) | yes | yes |
| 707–708 | `abandonTaskFromNotification` (slotted) | yes | yes |
| ~1160 | Approve queue handler | removes deferred_launch, *adds* approved | — |
| ~398–399 | `dashboard-server.ts /api/deferred-approve` | removes deferred_launch, *adds* approved | — |
| ~434–435 | `dashboard-server.ts /api/deferred-abandon` | yes | yes |

The `clearDeferralFlags` helper targets the abandon paths (lines 679–680, 707–708, dashboard abandon). The approve-flow sites (which remove `deferred_launch` but *add* `approved: true`) keep using `removeFrontmatterField` / `addFrontmatterField` directly — a helper that always clears both would be semantically wrong there.

Sites that clear only `deferred_launch` (complete, launch, keepalive, auto-start-evaluate) are left unchanged.

**`findSlotForTask`** (`src/mag.ts:649–659`):

- Uses `slotsFilePath()` (from `config.ts`), `parseSlotBlocks`, `getTask` (from `slots/markdown.ts`) — all already imported by `src/slots/index.ts`.
- Exported from `mag.ts`; imported by `dashboard-server.ts:13`.
- No circular dependency: `mag.ts` already imports from `slots/index.ts`.

**Private companion** `readTaskDeferralFlags` (`src/mag.ts:661–669`) is only used within `mag.ts` (keepalive logic) and is left in place — moving it is out of scope.

## Approach

*Suggested approach — agents may deviate if they find a better path.*

### Step 1 — Add `clearDeferralFlags` to `src/tasks/markdown.ts`

After the `removeFrontmatterField` function, add:

```typescript
export function clearDeferralFlags(filePath: string): void {
  removeFrontmatterField(filePath, "deferred_launch");
  removeFrontmatterField(filePath, "approved");
}
```

### Step 2 — Replace call sites in `src/mag.ts` and `src/dashboard-server.ts`

- Import `clearDeferralFlags` where needed.
- Replace sequential `removeFrontmatterField(f, "deferred_launch"); removeFrontmatterField(f, "approved")` pairs (abandon paths) with `clearDeferralFlags(f)`.
- Leave single-field removals and the approve-flow sites untouched.

### Step 3 — Move `findSlotForTask` to `src/slots/index.ts`

- Cut the function body from `src/mag.ts:649–659`.
- Paste it into `src/slots/index.ts` as an exported function (the required imports — `slotsFilePath`, `parseSlotBlocks`, `getTask`, `existsSync`, `readFileSync` — are already present).
- In `src/mag.ts`, import `findSlotForTask` from `./slots/index.ts` instead of defining it.
- In `src/dashboard-server.ts:13`, change the import source from `./mag.ts` to `./slots/index.ts`.

## Scope

**In scope:**
- `src/tasks/markdown.ts` — add `clearDeferralFlags`
- `src/mag.ts` — replace abandon-path pairs, move `findSlotForTask`, update imports
- `src/dashboard-server.ts` — update import source for `findSlotForTask`, replace abandon-path pair

**Out of scope:**
- Moving `readTaskDeferralFlags`
- Changing behavior of approve-flow sites
- Any other refactors suggested in the retrospective
